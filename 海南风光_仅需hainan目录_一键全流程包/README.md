# 海南风光从原始 NC 到九条出力曲线：一键完整流程

**唯一需要指定的外部输入是 `hainan` 文件夹。** 它下面放 `wind` 和 `solar` 两个文件夹（其中可再有 `ssrd` 子文件夹），或者分别放 `wind.nc`、`solar.nc` 两个多年份NC文件。本压缩包已带固定的海南80格海陆划分和边界文件，不需要事先准备任何NPZ、CSV、年份名单或代表年曲线。

## 1. 最简单的运行方法

解压本包，在包根目录打开终端，安装 Python 3.10+ 及依赖：

```powershell
python -m pip install -r requirements.txt
```

执行**唯一主程序**：

```powershell
python main.py --hainan 'C:\Users\你的用户名\Desktop\Xinnengyuan\hainan'
```

也可运行 `./run_all.ps1 -HainanDir 'C:\...\hainan'`。若NC就在本包旁边的 `hainan` 目录，把参数改为 `--hainan './hainan'`。主程序会依次调用 `scripts/00` 至 `scripts/05`，第0步到第5步逐条打印进度；任何一步失败会停止，错误原因不会被后续结果掩盖。

支持的输入布局：

```text
hainan/
├─ wind/
│  ├─ 1950.nc … 2025.nc              # 也可用一个含76年的NC
└─ solar/
   └─ ssrd/
      ├─ 1950.nc … 2025.nc           # 也可把NC直接放在solar/
```

若使用两个多年份文件，则为 `hainan/wind.nc` 和 `hainan/solar.nc`。主程序递归寻找两个资源入口内的 `.nc` 文件；不要求文件名必须是年份。一个只含**单一年份**的NC不够形成76年历史库；程序会明确报出缺失年份。

## 2. 需要的NC变量和计算口径

| 输入 | 必需变量 | 用法 |
| --- | --- | --- |
| 风NC | `valid_time`, `latitude`, `longitude`, `u100`, `v100` | 每个格点、每小时先取 `sqrt(u100²+v100²)`；31个海域格、49个陆地格分别等权平均 |
| 光NC | `valid_time`, `latitude`, `longitude`, `ssrd` | `ssrd` 为每小时累计J/m²，先对80格等权平均再除以3600，得W/m² |

时间按NC的UTC时间处理，删去闰年2月29日，要求1950—2025每年完整8760小时且不重复。网格须为海南8×10、80格，坐标与包内 `data/80网格海陆分类.csv` 匹配。`scripts/00_check_grid_mask.py` 使用包内海南省边界GeoJSON重新核对31海格和49陆格；`scripts/01_nc_to_cache.py` 进一步核对每个NC的经纬度顺序。包内 `data/原始NC文件清单.csv` 记录了本次实测所用152个NC的文件大小和SHA-256，便于检查数据版本；NC本身因体积约413 MB未重复压缩进包。

## 3. 主程序与全部模块

| 程序 | 作用 | 输入 → 输出 |
| --- | --- | --- |
| `main.py` | 一键主入口：识别 `hainan/wind`、`hainan/solar`，依次调用以下六步，记录来源与代码校验码 | `hainan` → `outputs/运行来源与程序版本.json` |
| `scripts/00_check_grid_mask.py` | 用海南边界核验每个网格中心的海陆属性 | 包内GeoJSON、网格CSV → `data/网格海陆核对.json` |
| `scripts/01_nc_to_cache.py` | 读取原始NC，计算格点风速和辐照度，空间平均并统一8760时间轴 | 原始NC → 风速和光伏两个76年NPZ缓存 |
| `scripts/02_classify_cluster_insert.py` | 三类资源年划分、`k=1` K-medoids、风电P10/P90片段插入、光伏P10低光日插入 | 两个缓存 → 三类年份总清单、九库候选、日志、曲线 |
| `scripts/03_power_curves.py` | 将九库插前插后资源换算为出力标幺并求全年最大利用小时 | 九库曲线 → 九条8760小时出力表和小时数表 |
| `scripts/04_verify_outputs.py` | 独立核验缓存、九库曲线、原极端片段保护、出力求和 | 以上结果 → `outputs/复核结果.json` |
| `scripts/05_plot_results.py` | 画九条未经平滑的8760小时插后出力曲线 | 九条出力表 → PNG |

如果需要逐步调试，各模块也可单独运行；`main.py` 是推荐入口。`requirements.txt` 列出NumPy、netCDF4、Matplotlib依赖。`FILES_SHA256.csv` 列出包内每个实际交付文件的大小、哈希和用途。

每个九库子目录均有**四个文件**：

| 文件 | 记录什么 | 如何用 |
| --- | --- | --- |
| `summary.json` | 本库19或38个年份、每个候选年的欧氏距离和、选定的代表年、阈值、全年和12个月目标、插前/插后极端数量 | 查代表年为什么被选中、是否达到目标 |
| `candidates.csv` | 风：本库同月全部连续≥3小时的P10/P90完整候选片段；光：已剔除代表年原有低光日的候选日历日期及来源年 | 查“可插什么” |
| `insertion_log.csv` | 每次实际插入的月缺口、本轮额度、历史来源、目标位置、长度或截断、低光频次 | 查“先插了什么、插在哪里、为何停止” |
| `curve_8760.csv` | 8760行插入前/插入后资源及修改标记 | 逐小时复核，也供下一步出力换算 |

`classifications_and_results.json` 是海风、陆风、光伏各自三类年份及代表年的总索引。两个NPZ分别存76年风速（每年海、陆两条）和76年辐照（每年一条），**不是额外需要用户提供的输入**。九条出力CSV把每类的插前、插后资源和出力放在同一8760时间轴；最大利用小时表是逐小时标幺出力求和 `H=Σₜpₜ`。`docs/九库详细计算报告_原工作区版.md` 附有各库年份名单和更完整的数值过程；其中旧绝对链接仅作历史参考，复算请以本包目录为准。

## 5. 年份分类与代表年计算

海风、陆风、光伏分别建库。风年资源指标为 `mean(v³)`，光年指标为 `ΣG/1000`（kWh/m²）。每类76年按指标由小到大排，**前19年为小资源、中间38年为平均资源、后19年为大资源**；指标相等时按年份先后。每库每个真实年是一条8760维曲线，计算到本库所有真实年的欧氏距离和，取距离和最小的年份作 `k=1` K-medoids中心；并列取较早年。所谓“聚合成一条曲线”是选一个完整真实年，**不是把多个年逐小时取平均**。

## 6. 风电P10/P90插入

对每个海风/陆风资源库独立求所有小时的P10和P90。逐月找每小时≤P10或≥P90且连续**至少3小时**的极大完整片段。库内逐年合格小时的平均数取整为全年目标，同法求12个月目标。候选是同库、同月、完整历史片段；均值排序后，P10从较小侧中位片段往更小方向，P90从较大侧中位片段往更大方向，用过不再用。

每批先处理**当前月缺口最大**的月份；同缺口先早月。月缺口 `m<3` 时冻结；`m>6` 时本批额度 `ceil(m/2)`；`3≤m≤6` 时额度为3小时；最后一批不超过全年剩余。目标位置从月初向后找，不能覆盖已有P10/P90越阈小时，每段两侧各隔3个正常小时，同一日历日最多一条新增片段。先试完整片段，本批允许比额度多0—2小时但不能超过全年目标；完整片段均不可行时才允许从历史片段**开头**截取最后一段，截后仍须≥3小时。批次达不到额度就回滚；全年剩余不足3小时或再无合法批次时终止并保留实际缺口。P10和P90共用同一条更新曲线，先P10再P90，程序最后验证原有越阈小时不变。

## 7. 光伏P10低光日插入

在本库所有历史天的24小时**日均辐照度**上求P10，一天均值≤P10即低光日。先从代表年可插日期中删除原本已是低光日的日期；原有低光日24小时不变。月缺口按天数从大到小排序，同缺口先早月，每批额度 `ceil(月缺口/2)`，受全年剩余天数约束。同月内按该月日历日期在历史库成为低光日的**频次**由高到低选，频次相同时先较早日期。

对选中月日，只取历史库**同月同日且本身为低光日**的候选，按全天24小时总辐照量排序。奇数个候选取中间那一天完整24小时曲线；偶数个取中间两天对应小时的平均曲线。以完整24小时替换代表年的同一月日，每批重算缺口。达到全年目标、月额度无法完成或无候选时停止；程序验证未选日期未改。

## 8. 九条出力使用的机组参数

本包保留先前**原机组参数**，未使用后来讨论的提高利用小时的设想参数。海风为切入/额定/切出 **4/11/25 m/s**、α=0.70；陆风 **2.5/9/18 m/s**、α=0.95。切入以下和切出及以上标幺为0；切入到额定为 `α(v³−v_in³)/(v_r³−v_in³)`；额定至切出为α。光伏为 `p=0.60×max(G,0)/1000`。九条曲线均为出力标幺；乘装机MW才能得到MW，不另计弃电。
